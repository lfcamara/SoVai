# Grill with Docs

Run the `grilling` skill together with the `domain-modeling` skill — the interview, and the writing-down that makes its conclusions outlive the transcript.

This ends where the design is settled and its trace is written. That is the whole outcome, and it is what separates this from `brainstorm`, which runs the same pair against an idea whose boundaries are still open and then carries it on into a PRD and a spec. A decision that only needed sharpening does not want those documents, so the work finishes here rather than continuing into the planning block.
